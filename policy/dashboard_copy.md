# Dashboard copy: concise by default

User direction, 2026-10-11: dashboards are working surfaces. Avoid repeated descriptions of what a section/organ does and generic ownership or disclaimer paragraphs. Prefer short headings, structured facts, counts and actionable exceptions. Nest and indent detail below its parent. Link longer explanations from documentation instead of displaying them repeatedly.

Keep relevant failure/staleness warnings and distinguish unavailable data from a passing result. Never invent counts or hide evidence failures for brevity. Source records and machine feeds remain authoritative. This rule governs future dashboard presentation work; it does not authorize unrelated bulk edits.
