## Reproduce

Against PyAutoMind main (e9c34daa4), from `PyAutoBrain/agents/conductors/intake`:

```
python3 -c "
import _intake as I; from pathlib import Path
c = I.census(Path('<PyAutoMind>'))
paths = {e['path'] for e in c['recent']}
print([e['slug'] for e in c['planned'] if e.get('prompt') in paths
       and any(r['path'] == 'planned.md#' + I._anchor(e['slug']) for r in c['recent'])])"
# ['hpc-keep-off-home-phase-b', 'interferometer-primary-beam-persistence-mirror',
#  'delaunay-nn-numba-remeasure']
```

On the rendered page these show as pairs, e.g. in Recent:

```
| 2026-11-12 | filed  | <a href="planned.md#hpc-keep-off-home-phase-b">hpc-keep-off-home-phase-b</a> |
| 2026-11-12 | filed  | <a href="draft/maintenance/workspaces/hpc_keep_temp_off_home_phase_b.md">Phase B: …</a> |
| 2026-11-12 | issued | <a href="planned.md#delaunay-nn-numba-remeasure">delaunay-nn-numba-remeasure</a> |
| 2026-11-05 | filed  | <a href="draft/feature/autolens_profiling/delaunay_nn_numba_optimal_remeasure_after_677.md">…</a> |
```

## Expected

`recent_events`' own docstring: "One row per task, not per event: a task that was
filed and later issued appears once, on its latest date". A planned row and the draft
its `prompt:` names are one task, so it should appear once, on the latest of the two
dates. Three of the 50 feed rows are spent on duplicates today.

## Actual

`recent_events` adds every dated backlog record ("filed") and then every dated
planned.md row, with no de-duplication between a planned row and its `prompt:`.
In-flight rows avoid this because `census` keys them by prompt (`by_prompt`).

## Likely fix location

PyAutoBrain `agents/conductors/intake/_intake.py`, `recent_events` (~line 1502): collect
the `prompt` paths of the planned rows and skip backlog records whose `path` is one of
them (the planned row carries the later, more specific event and its own copy payload).
Alternatively keep whichever of the pair has the later date.
