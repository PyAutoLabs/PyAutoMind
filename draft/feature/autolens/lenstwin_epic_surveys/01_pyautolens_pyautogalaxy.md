# LensTwin survey 01 — PyAutoLens and PyAutoGalaxy (read-only, 2026-10-28)

Clones surveyed: PyAutoLens `a8eb094` and PyAutoGalaxy `a108092` (both `main`, 2026-10-26, release 2026.10.26.1). Survey only; nothing was edited. PyAutoFit, PyAutoArray and PyAutoNerves were **not** on disk, so their APIs (`af.Model`, `af.Aggregator`, `af.Result`, `as_model`, the `SimulatorImaging` constructor, `Imaging.from_fits`, `apply_mask`, `apply_over_sampling`) are inferred from call sites only. ## §0 Agent rules (AGENTS.md; no CLAUDE.md in either clone)

- PyAutoLens sits at the top of the stack and may import autogalaxy, autoarray, autofit, autonerves; nothing imports autolens. PyAutoGalaxy must **never** import autolens. Public API is `autolens/__init__.py` (`import autolens as al`).
- Unit tests are NumPy-only; JAX/`xp` behaviour is validated only by `autolens_workspace_test` parity scripts; `xp` must be threaded through every nested call. A new config key must be mirrored into `autolens/config/`. LF endings. CI runs `pytest --cov` on 3.12 and 3.13; no lint gate. "If you changed public API, say so explicitly."
- Operate mixins: `OperateImage` (`autogalaxy/operate/image.py`) and `LensCalc` (`operate/lens_calc.py`); there is no `operate/deflections.py`.
- Shared blocks: never rewrite pushed history; sessions end at their deliverable; issues only via Mind prompt → `/start_dev` → `/create_issue` → one issue per task → PR; consult the organism standard before changing shared interfaces. "Library-first" is a merge-order gate (`PyAutoBrain/skills/ship_workspace/SKILL.md:13`, `skills/COMMANDS.md:84`): library PRs merge before linked workspace PRs; workspace CI runs libraries from the same-named branch (`autolens_workspace/AGENTS.md:59`).
