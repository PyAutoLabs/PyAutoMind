`HowToFit/scripts/chapter_1_introduction/tutorial_1_models.py` carried a stale
`__Paths__` block telling a reader who wants to clone **HowToFit** to download
`autofit_workspace` — a leftover from before the HowTo series split out of the
workspace repos. It was fixed on `feature/howtofit-tutorials-1-3` (commit
`6f335b2`, pushed 2026-09-14) and now reads
`https://github.com/PyAutoLabs/HowToFit`.

The fix landed in two of the three mirrors:

- `scripts/chapter_1_introduction/tutorial_1_models.py` — fixed
- `notebooks/chapter_1_introduction/tutorial_1_models.ipynb` — fixed
- `markdown/chapter_1_introduction/tutorial_1_models.md:104` — **still stale**,
  reads `https://github.com/PyAutoLabs/autofit_workspace`

## Scope

Regenerate the markdown mirror so it matches its `scripts/` source. Do not
hand-edit `markdown/` — find why the regeneration step that updated `notebooks/`
did not also update `markdown/`, and fix the gap rather than the symptom. If
markdown mirrors are generated by a separate command from the notebook ones,
that asymmetry is the actual finding and belongs in `HowToFit/AGENTS.md`.

## Why this is its own prompt

The line belongs to `feature/howtofit-tutorials-1-3`, not to
`howto-stale-self-location` (HowToGalaxy + HowToLens, issue HowToGalaxy#75),
which explicitly dropped HowToFit once the parallel fix landed. If
`feature/howtofit-tutorials-1-3` is still open when this is picked up, fold it
there instead of opening a second PR.
