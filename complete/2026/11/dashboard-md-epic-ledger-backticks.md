Review-minutes: 3
Unattended: ready
Lane: any
Filed: 2026-11-16

The Mind dashboard is generated by PyAutoBrain (`agents/conductors/intake/_intake.py`),
so the fix lives there; the symptom is on PyAutoMind's `dashboard.md`.

## Reproduce

On PyAutoMind main (e9c34daa4, render current per `intake dashboard --check`):

```
grep -c '<summary>.*`' dashboard.md          # 25
grep -o 'ledger: `[^`]*`' dashboard.md | head -2
# ledger: `draft/feature/autofit/nautilus_fast_likelihood_development_epic.md`
# ledger: `draft/maintenance/autocti/cti_upkeep_epic.md`
```

Every epic row in the Epics section (dashboard.md line ~244 onwards) is a one-line
`<details><summary>…</summary>` HTML block. GitHub does not process markdown inside an
HTML block, so the ledger path is shown with raw backticks around it on the page the
README links. The same row in `dashboard.html` is correct
(`ledger: <code>draft/…</code>`), and the same summary line already uses `<code>` for
code spans in the epic title — only the ledger is wrong.

## Expected

The ledger path renders as code (`<code>…</code>`), as it does on the Pages twin.

## Actual

Literal backticks around 25 ledger paths in dashboard.md. The stray-epic summary
(`… queued prompt(s) — ⚠️ not in `epics.md``) has the same defect when it fires.

## Likely fix location

PyAutoBrain `agents/conductors/intake/_intake.py`, `render_dashboard`:

```python
if e.get("ledger"):
    head += f" — ledger: `{e['ledger']}`"          # ~line 2417
```

Pass it through `_summary_label` (which escapes HTML and turns code spans into
`<code>`), i.e. `head += f" — ledger: {_summary_label('`' + e['ledger'] + '`')}"`,
and do the same for the stray-epic "not in `epics.md`" summary (~line 2431). Add a
markdown-page assertion next to the existing ledger fixture in
tests/test_intake_dashboard.py (~line 451).
